A children's story web page that displays an illustrated story using image pages and simple navigation. This repository is ready for GitHub Pages once published, with `index.html` as the web entry point.

- `index.html` — story viewer web page
- `Nugget AI cover.png` — cover image
- `Nugget AI pg 1.png` through `Nugget AI pg 7.png` — story pages
